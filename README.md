A simple Todo List web application built using Python and Flask.
This project allows users to add manage their daily tasks.

Features:
Add new tasks
Display all task
simple and clean interface
lightweight Flask backend

Technologies Used
python
flask
Html
SQLite


Usage: 
open your browser and go to:
http://127.0.0.1:8000
you can now add manage your tasks.
